# Radio Việt Nam (Android 6+)

Build APK bằng GitHub Actions (không cần cài Android Studio):
1. Tạo repo mới trên github.com, upload toàn bộ nội dung thư mục này (nhớ cả thư mục `.github`).
2. Vào tab **Actions** > workflow **Build APK** > chờ chạy xong (~3-5 phút).
3. Mở lần chạy đó, kéo xuống **Artifacts**, tải `RadioVN-apk`, giải nén lấy `app-debug.apk`.
4. Cài lên điện thoại (bật "Nguồn không xác định").
